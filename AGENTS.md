# Repository guidance

This repository contains **THE MAKER'S NOTEBOOK**, an immersive, cinematic newspaper portfolio experience.

For design, frontend, 3D, animation, interaction, responsive, or visual QA tasks, consult the `portfolio-studio` skill at:

`.agents/skills/portfolio-studio/SKILL.md`

Read the relevant references under `.agents/skills/portfolio-studio/references/` before making substantial design or implementation decisions:
- `visual-language.md`
- `motion-system.md`
- `3d-guidelines.md`
- `quality-gates.md`

Preserve the approved creative direction:
- A cinematic interactive newspaper documenting the evolution of a builder.
- A torn-paper global INDEX.
- A tactile horizontal bookshelf for five project books and their case studies.
- Editorial paper transitions and a character-led opening.
- Immersive desktop experience with an intentionally designed mobile equivalent.
- The workshop is a content chapter only; do not use a mechanic workbench as the site's primary visual metaphor.

Inspect the existing implementation before changing it. Keep changes scoped, preserve working behavior, and verify the result. Do not merge, deploy, publish, or change production settings without explicit user approval.
