# Visual Language — THE MAKER'S NOTEBOOK

## Creative premise
The site should feel like opening a carefully kept maker's notebook: tactile, collected, thoughtful, crafted, and quietly expressive. It should communicate curiosity and hands-on making without becoming cluttered or nostalgic pastiche.

## Composition
- Favor editorial layouts, strong alignment, asymmetry with balance, and deliberate negative space.
- Establish a clear focal point in each viewport.
- Treat the bookshelf and paper index as meaningful navigation objects, not decorative illustrations.
- Use layered depth sparingly to reinforce physicality and orientation.

## Typography
- Use a restrained typographic system with clear roles: display, section/title, body, labels, and metadata.
- Preserve legibility at every breakpoint.
- Avoid excessive font styles, weights, letter spacing, and all-caps labeling.
- Check line length, line height, wrapping, and contrast in real content—not only placeholder text.

## Color and material
- Use a compact palette grounded in paper, ink, wood, and workshop materials.
- Paper surfaces should feel tactile through subtle tone, grain, edge, and shadow—not heavy filters.
- Keep text contrast strong; texture must never reduce readability.
- Use accent colors intentionally for focus, active states, or meaningful emphasis.

## Components
- Buttons and controls should feel like physical objects only when their affordance remains obvious.
- Keep project covers visually distinct while preserving a consistent shelf system.
- Use consistent spacing, border treatment, shadows, radii, and interaction states.
- Avoid default-looking dashboard cards, glassmorphism, gratuitous gradients, and excessive pill badges unless explicitly justified.

## Content presentation
- Lead with the work and the story behind it.
- Give each project a clear title, concise premise, role, contribution, tools, and outcome where known.
- Never invent project outcomes, metrics, employers, credentials, or testimonials.
- Use real screenshots, artifacts, and project imagery when available; label conceptual visuals honestly.
